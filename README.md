# PawMatch

Final project for the Building AI course

## Summary- PawMatch is an AI-powered pet recommendation system that helps people choose the most suitable pet for their lifestyle. Users enter their hobbies, health conditions, stress levels, income, and living conditions. The system first filters out unsuitable pets, such as large animals for city apartments or furry pets for people with breathing problems, then ranks the remaining options with a scoring model. Future versions will learn from user feedback and monitor pet health, supporting responsible, lifelong pet ownership.
